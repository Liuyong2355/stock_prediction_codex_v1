## 结论

- E005: selected alpha=0.3, exit=0.25；三折 Score 0.331673 → 0.371482，官方 turnover 0.402321 → 0.169138，诊断 turnover 0.600098 → 0.390940。
- E006: selected alpha=0.3, exit=0.25；三折 Score 0.300029 → 0.358599，官方 turnover 0.481806 → 0.210786，诊断 turnover 0.530621 → 0.258241。

- 两模型均表明 C0 的 alpha=0.5 偏高、exit=0.15 偏窄；F1/F2 Score surface 在声明网格内单调改善。
- E005 的 alpha/exit 边际 Score 增益为 +0.023274 / +0.020221，alpha 略大，exit 高端开始出现平台。
- E006 的 alpha/exit 边际 Score 增益为 +0.030672 / +0.031413，exit 略大，尚未观察到平台。
- E005 的诊断换手改善占官方换手改善 82.4%，但平均 turnover gap 达 0.221802，标记为 missingness-sensitive turnover gain。
- E006 missing Top 仅 0.02%，仍同方向显著改善，提供低 missing-label 稳健性证据。
- F3 robustness 的 selected-anchor Score 变化为 E005 +0.032438、E006 +0.051540，支持 F1/F2 方向。
- 两模型仍命中 alpha 下边界与 exit 上边界，但依停止规则不再扩展。锁定 E005 + alpha=0.30 + exit=0.25 为 single-model postprocess V1，下一阶段进入模型信号研究。
