## 选择与确认

- E005 选择 alpha=0.5, exit=0.15；F1/F2 Score=0.323006，F3 Score=0.349007。
  三折均值变化：IC -0.009763，超额收益 -0.091005，turnover -0.336967，Score +0.069883；贡献分解为 IC -0.003905、收益 -0.027301、换手 +0.101090。
- E006 选择 alpha=0.5, exit=0.15；F1/F2 Score=0.291528，F3 Score=0.317030。
  三折均值变化：IC -0.010030，超额收益 -0.120170，turnover -0.354118，Score +0.066172；贡献分解为 IC -0.004012、收益 -0.036051、换手 +0.106235。

## 研究结论

1. E005 与 E006 的 turnover control 均有效：三折 turnover 分别下降 0.336967 / 0.354118，Score 分别提高 0.069883 / 0.066172。
2. C0 后 E005 的平均 Score 更高；下一阶段单模型首选 E005。
3. 提升主要来自 turnover；IC 与超额收益均有损失，并非同步改善。
4. EMA+hysteresis 相对 rank-only 的 IC 变化为 E005 -0.008889、E006 -0.008909；相对 raw 的 IC 保留率为 89.90% / 91.53%。
5. 在 selected alpha 下，将 exit 从 0.10 放宽到 selected exit 的 F1/F2 Score 边际贡献为 E005 +0.024049、E006 +0.029220。
6. F3 支持两项 F1/F2 选择：相对 raw Score 分别 +0.075246 / +0.068783，看过 F3 后未调参。
7. 两模型最优点都落在 alpha 下边界和 exit 上边界；按预注册规则不扩展本阶段网格。
8. 建议下一阶段以 E005 为单模型基线；当前证据不支持立即重做 LambdaRank，若后续研究应作为独立、重新设计的实验。
